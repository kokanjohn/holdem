Live draft connection — roadmap

Not built yet. Requires an NFBC account to inspect what the live draft room actually exposes.
  1. 1Sign up for an NFBC account and enter a live/mock draft to inspect the page — need to know if it's a WebSocket feed, polling, or server-rendered, before anything can be built.
  2. 2If a usable feed exists: build a Cloudflare Worker to relay it — a Worker avoids browser CORS/auth issues that would block calling NFBC directly from this page, and gives us a stable endpoint to poll from here.
  3. 3Normalize whatever NFBC sends into the same player/team shape this dashboard already uses, so the rest of the UI doesn't need to change.
  4. 4Wire the Worker's endpoint into this page, with the manual "Drafted" button kept permanently as a fallback — NFBC's page structure could change or the feed could be rate-limited mid-draft.
Until then, everything below runs on the manual "Drafted" button — click it as picks happen (yours or opponents') to keep the pool and your roster accurate in real time.
